<Callout title="En resumen">
  La referencia de la API se genera del esquema OpenAPI del backend en cada build, así que refleja el código de la revisión publicada. Las reglas que el esquema no expresa tienen páginas propias.
</Callout>

## API REST

Una página por operación, agrupada por tag. Las rutas son las del backend (`/v1/...`); desde el navegador se llaman bajo `/api` en el mismo origen. Las respuestas salen en camelCase dentro de `{ data, timestamp }`.

El esquema completo está en `docs/openapi/openapi.json` y, con el backend en marcha, en `http://localhost:8200/api/py/docs`. Para regenerarlo, ver [Actualizar la referencia OpenAPI](../guias/documentacion/actualizar-openapi.mdx).
