# Typescript verification

Use Vitest/Testing Library with the i18n render helper (`tests/render-with-intl.tsx`) for observable interactions, error/loading/recovery and cache invalidation. Place tests (paths relative to `frontend/`) in `tests/api/features/<feature>/` (request fns, keys, hooks), `tests/models/features/<feature>/` (zod/model rules), `tests/components/features/<feature>/` (UI states) or `tests/unit/` (shared/http, BFF helpers). The transport double is `vi.mock("@/shared/http/client")` replacing `authHttp`/`localHttp`; MSW is not installed. A session or tenant change needs a regression test proving no cached data from the previous scope is shown. Playwright owns the TypeScript E2E suite in `tests/end-to-end/` (`*.spec.ts` smoke; `*.integration.spec.ts` only with `E2E_INTEGRATION=1` via `just integration`); use webapp-testing for browser reconnaissance, role/label selectors, console/network and screenshots. No duplicate Python product suite.
